# 📸 Galeria de Fotos com SQLite e Google Maps

Aplicativo mobile desenvolvido em **React Native + Expo (TypeScript)** para captura de fotos, registro de localização via GPS e persistência local no SQLite.

## 🚀 Como Instalar e Rodar

Abra o terminal na pasta raiz do seu projeto e execute os comandos abaixo:

### 1. Instalar as dependências do projeto

npm install

npx expo install expo-sqlite expo-image-picker expo-location react-native-maps

#### 2. iniciar o projeto expo

npx expo start
